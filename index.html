User Guide

Everything you need to know to get started with Moon bot.

1. Getting Started

First, invite Moon to your server by clicking the "Invite Bot" button. Ensure that you grant the bot the necessary permissions so it can function properly in your server.

2. Basic Commands

  • /help - Displays a list of all available bot commands.
  • /ping - Checks the bot's current speed and API latency.
  • /setup - Configures basic settings and modules for your server.

3. Need Help?

If you encounter any issues while using a command, or if the bot goes offline, feel free to join our Support Server and reach out to our staff team for assistance.

Privacy Policy

How we handle and protect your data.

Last updated: Today

1. Data Collection

Moon bot only collects the data necessary for its core features to function correctly. This data includes:

  • Server IDs and Channel IDs (used to save server-specific configurations)
  • User IDs (used for command execution logs and leveling systems, if applicable)
  • We do not read, store, or log any personal direct messages (DMs) or general chat messages unless explicitly required for a specific moderation command.

2. Data Security

Your data is securely stored in our databases. We value your privacy and assure you that your data is never sold, traded, or shared with any third-party companies or individuals.

3. Data Deletion

If you wish to have all your server's data completely wiped from our database, you can kick the bot from your server and open a data deletion request ticket in our support server.
